# Capstone-Project-CS-for-Oregon

## Instalation and use


1. Clone the repo and cd into it
2. Install Node.js on your machine's platform
3. Install npm on your machine;s platform
4. Using VSCode is recommended
5. Open up the terminal in VSC and run this command while cd's into the backend and front end directories ```npm install``` to install the project's dependencies.
6.  In the backend folder run ```npm run dev``` then open up a new terminal and in the frontend run ```npm start```.
