# CS for Oregon

CSforOregon.org is the home website of the CS for Oregon organization. CS for Oregon provides the information that educators, administrators, councilors, and legislators need to know about expanding equitable Computer Science education to K-12 students across Oregon.

## Authors and Contributors
Jill Hubbard and Jenna Borberg are the authors of the site who came up with the overall design for the structure of the site.

The development team consists of Jack Rundle, Anna Vosko and Joel Gochez who have coded and developed the site as well as modifying and implementing the site's styling based of the initial designs.

## Purpose
The old CS for Oregon site was a wordpress site that needed to be customized and modernized. The CS for Oregon dev team have developed from scratch a new site based off of React, a modern web page development framework.

## Value Proposition

A custom and modern web application provides the ability for more fine grained control over the look and function of the site. A wordpress site in contrast provides easy to use tools such as dragging and dropping elements, and easily editable text within boxes that help people without technical knowledge build a simple site. What a custom modern site provides over a wordpress site that CS for Oregon needed are:
 * Control over the site's navigation system.
 * CSS animations and styling.
 * A database to store data displayed on the site.
 * Server side scripts to implement site features.
 * An admin page to interact with the database.
 * Control over the site's appearance on mobile devices.
 * Contact form processing and site email forwarding.

## Installation and Use
Clone the Repository:

Copy the repository URL from the 'Clone' button on GitHub.
In your terminal, type git clone [URL] (replace [URL] with the copied URL) and press Enter.

### Install Node.js and npm:

Download Node.js from https://nodejs.org/en/download/.
Npm is included with Node.js.

Using an Editor:
Download and install Visual Studio Code from https://code.visualstudio.com/Download.

Install Dependencies:
Open a new terminal in VSCode.
In the terminal navigate to the frontend directorie using the command `cd vite-project`
Run the command `npm install`. This will install all needed packages and their dependencies for the project.

## Starting Locally

Starting Locally
To start the project on your local machine, follow these detailed steps:

Open the Project in an Editor: Open the project code in a text editor, such as Visual Studio Code, which you can download from here.https://code.visualstudio.com/Download

Access the Terminal: Open a new terminal window within your editor, this can be done from the taskbar or menu at the top. Look for the Terminal button and select the New Terminal Option from the drop down menu. Alternatively you can try pressing: Ctrl+Shift+`

Check Project Files: In the terminal, type ls and press Enter. This will list the files in your project directory. You should see files like README.md, vite-project, etc.

Start the Frontend:
In the second terminal, type cd vite-project and press Enter.
Then, type npm run dev and press Enter. Look for a line saying Local: http://localhost:5173/ (the number might be different).
Copy the http://localhost:... URL and paste it into your preferred web browser.
